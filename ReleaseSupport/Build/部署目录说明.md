# 当前 Debug 部署目录

复制整个 `Aron_V2/bin/x64/Debug` 到现场，启动 `Visual Inspection.exe`。

```text
Debug/
  Visual Inspection.exe                  程序
  Visual Inspection.exe.config           .NET 加载配置，必须与 EXE 同目录
  Visual Inspection.exe.visionpro-references.txt  VisionPro 版本审计清单
  Visual Inspection.pdb                  Debug 诊断符号
  *.dll                                  托管/原生运行依赖，保留
  x64/SQLite.Interop.dll                 SQLite 的 x64 原生运行库，保留
  LmiSdk/                                已固定版本的 GoSDK，保留
  Aron.PluginContracts.dll               外部插件公共接口，随主程序保留
  Plugins/PreWeld/                        可选焊前寻址 DLL/PDB/plugin.xml，默认不加载
  Project/                               仅配置、参数、算法文件
    Config/
      General/                           存图、语言、界面布局、日志显示选项
      Plugins/                           Enabled.xml 与各插件的独立配置
      Jobs/Parameter.xml                 Job、相机、位置、Limit 参数
      Security/                          用户、角色与权限
      Communication/
        Communication.xml                通讯方式选择
        VPPOutput.xml                    检测输出映射
        Profinet/                        Profinet 参数及 PLC 输入映射
        S7/                              S7 参数、输入点表、输出点表
        TcpIp/                           TCP/IP 参数（有配置时生成文件）
    VPP/JobN/CamN/PosN/                   Camera.vpp、Inspection.vpp
  Data/
    Database/VisionData.db               正式数据库
    Database/LegacyOrders.db             旧 mydata.db，保留历史记录但不再用于启动初始化
    Stats/CameraStats.xml                相机统计
    Plugins/PreWeld/                     可选焊前寻址的原始数据与汇总/回放 XML
  Logs/
    Application/                        应用日志
    Plugins/PreWeld/                     插件日志
    VisionPro/                          DLL 检查与诊断日志
    Diagnostics/                        独立运行事件、流程节点与异常报告
      Crash/                            异常堆栈及最近事件
      Packages/                         Help → Export diagnostics 导出的 ZIP
```

迁移不改 XML 内容、通讯点位、用户密码散列和 VPP。旧版目录在首次启动时自动迁移到分类目录；已有新版分类配置优先，不用旧副本覆盖。数据迁移遇到目标重名会停止，避免覆盖数据库。

根目录旧 Config 中的 S7 配置仍在使用，已迁到 `Project/Config/Communication/S7`，并同步修改所有读取、保存和重建点表路径。根目录 PlcInput.xml 是未使用的旧副本，实际使用的 `Project/PlcInput.xml` 已迁到 Profinet 分类。

已直接删除空 Recipes、旧 Release、bin/Debug 重复输出、各 Validation 输出、x86 SQLite 原生副本和运行无关的 API 文档 XML；未制作文件备份。`DeploymentCleanup.latest.json` 仅记录清理清单和校验值。

Release 构建能力仍保留，旧 Release 输出已删除。日常使用 Debug 即可。API 文档 XML 不再复制到部署目录，x64 构建不再复制 x86 SQLite 库。

配置、VPP、数据库、统计、日志、GoSDK 共 97 个保留文件在迁移前后校验一致。独立 `--organize-project` 参数仅整理文件，不初始化 VisionPro、不连接相机/PLC、不打开数据库；正常启动会执行同样的旧目录迁移。
