# 操作日志与 Project 自动备份

## Database 菜单

Database 现在包含“数据库”和“操作日志”。数据库保留原有功能和权限入口。

操作日志按天保存在 EXE 同级 `Logs/Operations/yyyy-MM-dd.jsonl`，不放入 Project，不随普通日志删除，也不自动设置保留期限。记录电脑本地时间及 UTC 偏移、当前登录用户、窗口、操作和版本/构建信息。

记录界面点击、菜单命令、参数选择/编辑、表格编辑、打开/关闭窗口、键盘保存命令，以及登录验证、账号维护、相机/算法 VPP 保存结果。自动刷新、PLC 输入和连续检测不作为人为操作。按钮点击表示操作请求，不代表成功；VPP 保存等另有成功/失败记录。程序默认账户通过 ApplyPermissions 同步，未登录时为 Guest。

日志查看支持日期、关键词、最新优先（单次最多 5000 条）、双击详情和导出当前查询的 CSV。全部原始记录仍保留在磁盘上。密码不写入日志；自由文本及可能含敏感内容的表格值不保留明文，仅记录编辑位置。数字表格修改记录前后数值。Cognex 内嵌控件记录交互位置和保存结果，不承诺还原其所有私有工具参数变更。

日志后台写入，正常关闭会等待刷盘。异常断电/磁盘损坏不能保证最后尚未刷盘的记录；写盘失败会在主日志提醒、在操作日志窗口提示，并排队重试。本功能不具备防管理员篡改的合规审计能力。

## General 自动备份

General 使用 B 方案的纵向卡片列表，包含图像存储、FTP 上传、显示与程序、Project 自动备份。前方复选框沿用原有启用开关；显示与程序默认启用，复选框禁用且勾选。每项右侧齿轮均可点击，包括未启用的功能，方便提前配置。

齿轮弹窗使用独立参数副本：取消或关闭不改变页面参数；确定仅将修改暂存到 General；仍需主页面右下角 Save 才写入原配置并按原有回调生效。切换分类时仍有未保存提示。右侧预留滚动区域，后续功能增加时自动纵向滚动。卡片、说明、弹窗字段和按钮支持中文/英文；配置值及路径不翻译。

General 下方新增：启用自动备份、备份间隔天数、保留天数、备份路径。天数为 1～36500 的整数。默认关闭、间隔 7 天、保留 30 天，默认路径为 EXE 同级 Backups。点击 General 右下角 Save 后生效，不需重启。

配置：`Project/Config/General/ProjectBackup.xml`。
成功时间和运行状态：`Data/Backups/ProjectBackupState.xml`。

程序运行时每分钟检查一次，启动后首次检查约 30 秒。启用且没有成功记录时会做首次备份；后续距上次成功达到间隔天数再执行。程序退出期间不会执行，重新打开后检查补做。失败至少间隔 5 分钟再重试。

只压缩整个 Project（包含其中的 VPP），不包含 Logs、Data 或 SDK。ZIP 的 Project 目录保留原目录结构，另含版本说明。备份路径不能位于 Project 内，也不接受目录链接。后台读取不锁住配置/VPP 保存；检测到期间文件新增、删除或长度/更新时间变化时放弃本次不完整包，后续重试。

ZIP 文件名以 `AronProjectBackup_<源目录标识>_` 开头，含 UTC 时间和随机标识。清理仅在备份成功后删除本实例生成、文件名符合格式且超过保留期的 ZIP，保留刚生成的包。其它文件、其它源目录备份不会删除。

恢复时关闭软件，先核对备份内容，再从 ZIP 提取 Project 到目标软件目录。不会自动恢复或覆盖正在使用的配置。备份可能包含现场账号和参数，请妥善保管；不上传 GitHub。

## 验证

`Tests/OperationsBackupTests.cs` 验证并发写入、查询、密码排除、ZIP 内容、定向保留期清理、递归路径拒绝、天数范围、调度边界，以及独立窗体与 General 中英文布局。验证不调用主程序启动流程、不取像、不连接 PLC。
