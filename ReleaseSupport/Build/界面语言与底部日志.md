# 界面语言和底部日志

## 使用

Setting → Setting → General 的 Language 可选择 English / 中文。修改选择本身不生效，点击原 Save 后才保存并切换。配置沿用图片/程序常规设置 XML，增加 Language 字段（en / zh-CN）；旧配置没有此字段时默认为英文。

主界面日志位于相机区下方，拖动灰蓝色横向分隔条可调节高度。计数、Job/Pos/Engine/Cam 和原操作按钮仍跟随相机区。Online/Offline 原按钮位于右上角、标题栏关闭按钮下方，颜色和点击处理未替换。相机显示控件的 AutoFit 开启，仅调整显示缩放，不改变原图或取像/算法参数。

## 实现边界

- UiLanguage 只维护本程序界面标题、菜单、标签、按钮、表格表头的中英文文本；已打开窗体即时更新，新窗体也会应用当前语言。
- 不更改 CultureInfo，因此数字/日期解析行为不变。输入框值、Job/Cam/Pos/Engine 标识、参数名和绑定字段、原始日志、通讯数据不翻译。VisionPro 自带控件及其内部界面不遍历，不替换其安装语言。
- 当前提供常用自有界面文案字典。未录入的技术说明、异常原文仍保持原文，并非对未知字符串进行自动机器翻译。常规/限值/相机设置的保存成功提示及设置中心未保存确认已接入语言。
- 未替换 Save、Offline/Online、日志过滤或详情事件，通讯服务源文件及 GoSDK DLL 未改动。
- General 的行内表格明确指定列号，并按原生 ComboBox 实际高度安排布局；标签按实际输入控件中心对齐，而不是只对齐包装面板。
- 设置中心保留固定右下角 Save、页面复用及配置变化后的缓存失效逻辑。

## 离线验证

- `Tests/LanguageLayoutTests.cs`：中英文往返、运行状态文本、菜单/表头、输入值/参数键/颜色保护、原 XML 序列化、选择未保存不切换、新打开页面自动应用语言、实际 ComboBox 中心线、三种窗口尺寸和分隔条拖动。
- `Tests/DisplayAutoFitProbe.cs`：实际 CogRecordDisplay，仅显示合成位图；三种尺寸下 AutoFit 和原图保留，实际相机视图的 Job/Cam/Pos/Channel getter 不因语言改变。
- `Tests/SettingsCenterTests.cs`：复用、失效、原 Save 点击事件、统一页脚、实际输入控件中心线、语言行和原表格/通道数据。
- `Tests/DesignModeStartupTests.cs`：设计器不启定时器、运行事件或 PLC，检查新底部日志布局。
- 模拟 S7 回归及 GoSDK 打包校验。

测试没有执行 Program.Main、Bootstrap、真实相机采集、算法 Run、GoSystem 或 PLC 连接。主布局测试使用四块占位面板，而非实拍图；显示控件测试单独使用合成位图。正常 Debug 输出保留原有 Project 配置和 VPP。
