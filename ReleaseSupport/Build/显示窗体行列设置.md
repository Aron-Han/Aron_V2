# 显示窗体设置

入口：Setting → Setting → 左侧“显示窗体设置”（英文 Display Layout）。

- 行数、列数均可设置为 1～16。
- 点击右下角 Save 后立即重新排列现有相机显示控件，并自动保存供下次启动使用。
- 按现有相机顺序从左至右、从上至下填充。容量不足时自动增加行数，不隐藏相机；容量超过相机数时保留空白位置。
- 窗口或日志分隔条调整后，图像显示随单元格缩放；网格过密时允许滚动，保留可操作的控件区域。
- 未保存时不改变主界面。首次未配置时保留原来的一行排列。

配置文件位于程序 EXE 同级的 `Project/Config/DisplayLayout.xml`，例如正常 Debug 输出目录：

`Aron_V2/bin/x64/Debug/Project/Config/DisplayLayout.xml`

只在点击 Save 时创建或更新此独立文件，不修改相机、算法、统计或通讯配置。重新排布使用同一批相机控件实例，不调用取像、算法 Run 或 PLC 接口，不重建统计绑定或事件。

General 的 Save type 仍使用原 BMP/PNG 控件及原保存逻辑。本次修复其嵌入设置中心后原生 ComboBox 高度变化带来的裁切，按实际高度预留内联行和边框留白。

验证脚本：`Tests/DisplayLayoutSettingsTests.cs`，使用独立临时布局配置，检查下拉框边界、网格保存/重载、相机顺序和实例/标识保留、缺少格子时补行、中英文、SettingsCenter 的右下角 Save 和未保存保护。测试不启动真实取像或 PLC 通讯。
