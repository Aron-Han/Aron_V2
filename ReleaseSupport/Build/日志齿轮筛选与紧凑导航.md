# 日志齿轮筛选与紧凑导航

## 界面

- 顶部五个主菜单仍是原菜单对象、权限和事件，图标/文字组合在每个菜单项中独立居中；高度从原 80 逻辑像素缩至约 64，图标 28 逻辑像素。
- 右上角 Offline/Online 使用原按钮，增大为 224×46 逻辑像素（150% DPI 为 336×69），12pt 字体，按左侧实际菜单项中心线居中。运行时仍控制其颜色、可用状态及文本。
- 相机/日志间使用 10 逻辑像素灰蓝拖动条，中间绘制两条把手线；仍是原 SplitContainer 的拖动行为。
- 日志采用浅蓝灰细边框的小圆角整体容器，包住筛选栏与表格；取消 Log 标题、事件数量和底部 Auto Scroll。表格自身无深色矩形框。
- 同行最右侧齿轮打开菜单；Auto scroll 复用原滚动状态，未另建滚动逻辑。菜单支持连续勾选多个选项，点外部关闭。

## ALL 显示类别

齿轮内提供：系统/启动、相机/取像、算法/检测、通讯。默认全部勾选。选择立即影响 ALL 的显示，取消全部时 ALL 为空，但缓存和日志文件不清除。恢复勾选可重新显示尚在原有 2000 条 UI 保留范围内的记录。

Warning 和 Communicate 不应用 ALL 的类别选项，继续使用原来的警告/通讯匹配。原始多行日志、详情复制及文件日志不变。

现有发布端只提供文本和颜色，因此类别在显示层按关键词推断：先识别原通讯消息，再识别相机/取像、算法/检测，其余归系统/启动；不修改 PLC 协议或发布端。这不是对每条历史消息的人工标注。

## 记忆设置

独立 UI 偏好文件为 EXE 同目录下的 `Project/Config/LogView.xml`。只有用户修改菜单选项才写入；打开菜单/恢复偏好不会覆盖文件。文件不存在或损坏时使用默认全部显示、自动滚动开启。修改用临时文件再替换；写入失败保留当前会话选项，不影响主程序。

菜单支持原中英文切换；无新增相机/通讯配置字段。原 Parameter.xml、ConfigSaveImage.xml、Communication.xml 和 VPP 不改动。

## 验证

`Tests/LogToolbarTests.cs`：隐藏/恢复、排除新消息但保留缓存、Warning/Communicate 独立、偏好保存与重开、原偏好不被默认覆盖、齿轮实际弹出与中文菜单、三种尺寸下菜单/Online 中心线及大小。

原 `LogPanelTests`：多行原文、筛选、限量缓存、自动滚动关闭时阅读位置、文件日志不受显示筛选影响；`LanguageLayoutTests`：底部拖动布局、语言和原数据保护；模拟 S7 通讯回归。

测试仅使用独立窗体、占位图像面板、合成日志及临时偏好文件，不运行 Program.Main、Bootstrap、实际相机/算法或 PLC。
